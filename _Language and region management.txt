How to manage lang and region :

################## Systemview			
			
Logo vue système :
			<path>firstfile(
                    "${bobmediapath}/_systemmedia/_logosyst/clearlogos/lang-${lang}/" + {system:theme} + "-${lang}.png",
					"${bobmediapath}/_systemmedia/_logosyst/clearlogos/region-${region}/" + {system:theme} + "-${region}.png",
					"${bobmediapath}/_systemmedia/_logosyst/clearlogos/" + {system:theme} + ".png",
					"${bobmediapath}/_systemmedia/_logosyst/clearlogos/lang-${lang}/" + {system:theme} + "-${lang}.svg",
					"${bobmediapath}/_systemmedia/_logosyst/clearlogos/region-${region}/" + {system:theme} + "-${region}.svg",
					"${bobmediapath}/_systemmedia/_logosyst/clearlogos/" + {system:theme} + ".svg")</path>

Pointeurs vue system :
					<path>firstfile(
					"${themePath}/_systemmedia/pointers-r/region-${region}/" + {system:theme} + "-${region}.png",
					"${themePath}/_systemmedia/pointers-r/" + {system:theme} + ".png")</path>

Theme system generique hardware :
			<path>firstfile(
					"${themePath}/_systemmedia/videosyst/hyperspin/rightart/region-${region}/" + {system:theme} + "-${region}.png",
					"${themePath}/_systemmedia/videosyst/hyperspin/rightart/" + {system:theme} + ".png")</path>
Bezel vue système :				
		<intbezelsyst>firstfile(
					"${themePath}/_systemmedia/bezelsyst/region-${region}/" + {system:theme} + "-${region}.png",
					"${themePath}/_systemmedia/bezelsyst/" + ({system:theme}) + ".png)</intbezelsyst>

################## Gameview

Logo de la vue jeu : géré par région du jeu
			<path>firstfile("${bobmediapath}/_systemmedia/_logosyst/clearlogos/region-" + {game:region} + "/"  + ({game:system:theme}) + "-" + {game:region} + ".png",
			"${bobmediapath}/_systemmedia/_logosyst/clearlogos/"  + ({game:system:theme}) + ".png")</path>

Pour les pointeurs de jeu : géré par région du jeu
			<path>firstfile("${themePath}/_systemmedia/pointers-r/region-" + {game:region} + "/"  + ({game:system:theme}) + "-" + {game:region} + ".png",
			"${themePath}/_systemmedia/pointers-r/" + {game:system:theme} + ".png")</path>
			
Pour les background de jeu géré par la région du jeu :
			<path>firstfile(
			"${themePath}/_viewgame/hyperbat/fondsysteme/region-" + {game:region} + "/"  + ({game:system:theme}) + "-" + {game:region} + ".png",
			"${themePath}/_viewgame/hyperbat/fondsysteme/" + {game:system:theme} + ".png",
			"${themePath}/_systemmedia/_fanartsysteme/fresh/" + {game:system:theme} + ".jpg")</path>
			
Pour les images de hardware quand ils existent :			
			<path>firstfile(
			"${bobmediapath}/_gametheme/${system.theme}/Hyperbat/_default/Console-" + {game:region} + ".png",
			"${bobmediapath}/_gametheme/${system.theme}/Hyperbat/_default/Console-${region}.png")</path>
